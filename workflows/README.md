# Nashira workflows

This directory contains reusable Nashira workflow definitions and templates intended for publication.

Workflows are code-backed operational artifacts. Their normal execution is deterministic and does not require an LLM or consume model tokens. A workflow can still invoke an external service that has its own usage or cost model.

Do not include credentials, tokens, customer identifiers, production addresses or environment-specific secrets. Use documented input and credential references.
