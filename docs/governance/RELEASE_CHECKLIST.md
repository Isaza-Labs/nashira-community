# Release checklist

## Identity and authority

- [ ] The release approver is authorized by Isaza Labs LLC.
- [ ] The release tag, commit and publication date are final.
- [ ] The release contains only project-owned material or properly licensed third-party material.

## Licensing and provenance

- [ ] Root and path-specific license files are correct.
- [ ] All accepted contributions have DCO sign-off.
- [ ] Third-party and AI-assisted material has been reviewed.
- [ ] The SBOM and third-party notices match the built artifacts.
- [ ] Code, workflows and skills/specifications carry the correct Apache 2.0 scope notice.
- [ ] Trademark statements identify Nashira as unregistered and do not use `®`.

## Security and quality

- [ ] Tests and required manual regressions pass.
- [ ] Secret scanning and dependency review are complete.
- [ ] No unresolved critical or high-severity security issue affects the release.
- [ ] Upgrade, rollback and data-migration procedures are verified.
- [ ] Security reporting and emergency contacts are active.

## Publication

- [ ] Release notes distinguish verified behavior, known limitations and breaking changes.
- [ ] Documentation links resolve from a clean checkout.
- [ ] Images and packages are reproducible or their provenance is recorded.
- [ ] Release artifacts are hashed and, when available, signed.
- [ ] The support status and supported versions are stated.
