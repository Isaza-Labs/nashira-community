All project-owned material is licensed under the **Apache License, Version 2.0**. The repository distinguishes three scopes so each kind of artifact remains unambiguous when copied or distributed independently.

| Scope | Repository treatment | License |

| Skills and specifications | `skills/` and `specs/` | Apache License 2.0 |

The `workflow.v1` contract and conformance kit also use Apache License 2.0. The complete license text is stored in the root `LICENSE`. Scoped notices make the three content classes explicit without changing the license terms.

Before publishing a release, the release owner must verify:

1. the owner, licensor and copyright notice;
2. the Apache 2.0 scope notice for code, workflows and skills/specifications;
3. the origin and applicable license of third-party material;
4. the dependency inventory, SBOM and required notices;
5. that no file claims Nashira is a registered trademark;
6. that accepted contributions have the required DCO record.
